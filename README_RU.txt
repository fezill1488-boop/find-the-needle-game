# Stink War Legacy 2 — мобильный прототип

Это стартовый игровой прототип для дальнейшей разработки. В нём есть:
- мобильное управление кнопками;
- добыча золота и найм рабочего, мечника и лучника;
- вражеские волны и особый удар;
- три тестовые главы с повышением сложности;
- простая оригинальная графика на Canvas без файлов оригинальной игры.

## Как запустить на телефоне
1. Распакуйте ZIP.
2. Откройте `index.html` в браузере, если файловый менеджер позволяет.
3. Если браузер не открывает локальную игру, загрузите проект в новый публичный репозиторий GitHub и включите GitHub Pages в Settings → Pages. После публикации откройте ссылку Pages на телефоне.

## Подготовка к Яндекс Играм
Этот архив — прототип, а не уже опубликованная игра. Чтобы выпустить игру:
1. Проверьте игру по ссылке HTTPS (например, через GitHub Pages).
2. Создайте проект в кабинете разработчика Яндекс Игр.
3. Следуйте актуальным требованиям кабинета к HTML5-играм и загрузке архива.
4. Перед публикацией добавьте необходимые SDK-интеграции, экран паузы/звука и протестируйте разные размеры экрана.

## Важно
Название используется как рабочее. Это фанатский прототип, не связанный с Max Games Studios. Не копируйте защищённые изображения, музыку, код или другие материалы оригинальной игры. Для публичного релиза желательно выбрать собственное уникальное название и визуальный стиль.
