STINK WAR LEGACY 2 — ПРОТОТИП 2

Что нового:
- Лобби с кнопкой «Играть» и декоративными разделами.
- Выбор одной из трёх глав.
- Игровое поле с базами, золотой рудой и юнитами.
- Кнопки найма рабочего, ученика и мечника.
- Рабочие приносят золото; юниты отображаются на поле.
- Интерфейс адаптирован для мобильного экрана.

Как обновить GitHub Pages:
1. Распакуй архив.
2. Открой свой репозиторий GitHub.
3. Замени существующий index.html этим index.html (в корне репозитория).
4. Нажми Commit changes.
5. Подожди пару минут и обнови опубликованную страницу.

Музыка лобби:
- Файл lobby_music.mp3 извлечён из видео, присланного пользователем.
- Музыка зациклена (loop), играет в лобби и останавливается во время уровня/паузы.
- Из-за ограничений браузеров музыка начинает играть после первого касания экрана.
- Для GitHub Pages загрузи index.html И lobby_music.mp3 в корень репозитория.
