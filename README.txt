FIND THE NEEDLE — HAYFIELD (прототип)

Что внутри:
- index.html — вся игра в одном файле.
- 3D-сцена на Three.js, подключаемом через CDN.
- Мобильное управление: джойстик слева, обзор свайпом справа.
- ПК: WASD, мышь, E для подбора, Shift для бега.
- Поиск игл, монеты, магазин трёх улучшений и сохранение в localStorage.

Проверка:
Открой index.html через хостинг, который поддерживает HTTPS и ES-модули. Для GitHub Pages включи Settings → Pages → Deploy from a branch → main / root.

Важно:
Это первый прототип, не финальная публикация в Яндекс Играх. Для загрузки на платформу нужно проверить актуальные требования кабинета разработчика, протестировать игру на мобильном устройстве и добавить нужную интеграцию SDK, если используемая функция Яндекс Игр этого требует. Внешняя библиотека Three.js загружается с jsDelivr, поэтому для запуска нужен интернет.
