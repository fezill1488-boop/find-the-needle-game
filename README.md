# НомерЗнаток — коллекционная браузерная игра

Оригинальный HTML/CSS/JavaScript-проект для телефонов и компьютеров. Нет внешних библиотек и не используются ресурсы из сторонних игр.

## Что уже работает
- Викторина из 10 вопросов за раунд.
- 12 стилизованных номерных карточек и флаги стран.
- Коллекция: открытые/закрытые карточки, редкости и цены.
- Монеты за ответы, автоматическая награда за хороший раунд.
- Опыт, уровни, достижения, очки и сохранение через localStorage.
- Самостоятельно синтезируемые звуковые эффекты на Web Audio API: нажатия, прокрутка, правильный/неправильный ответ, монеты, открытие карточки и уровень.
- Адаптивный интерфейс для Android.

## Запуск через GitHub с телефона
1. Скачай ZIP и распакуй на телефоне.
2. На github.com создай публичный репозиторий, например `nomerznatok-game`.
3. Открой репозиторий → **Add file → Upload files** и загрузи `index.html`, `style.css`, `game.js`, `README.md` отдельно из распакованной папки.
4. Открой **Settings → Pages**.
5. В **Build and deployment** выбери `Deploy from a branch`, ветку `main`, папку `/(root)`, нажми **Save**.
6. Подожди публикации, затем открой появившуюся HTTPS-ссылку и проверь игру.

## Архив для Яндекс Игр
ZIP для загрузки должен содержать `index.html`, `style.css` и `game.js` прямо в корне, без дополнительной папки. Этот проект — стартовая HTML5-версия; перед отправкой подключи актуальные требования и SDK Яндекс Игр в кабинете разработчика. Встроенная реклама, облачные сохранения и таблицы лидеров пока не подключены.

## О звуках и графике
Звуки генерируются кодом при запуске и не копируются из чужого APK. Номерные знаки стилизованы для игрового процесса; примеры комбинаций являются вымышленными и не предназначены для идентификации реальных автомобилей.
