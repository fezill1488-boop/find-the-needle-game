# НомерЗнаток — коллекционный номерной кликер

Мобильная HTML5-игра на чистом HTML, CSS и JavaScript. Все номерные комбинации в игре вымышленные.

## Игровая механика
- Нажимай «Тапнуть и открыть» или сам номерной знак, чтобы получить случайный номер.
- Редкости и шансы выпадения: обычный — 65%, необычный — 22%, редкий — 9%, эпический — 3,2%, легендарный — 0,8%.
- Цена зависит от редкости: от десятков рублей за обычный номер до десятков тысяч за легендарный.
- Инвентарь ограничен 30 номерными знаками. Если он заполнен, продай один номер или нажми «Продать всё».
- Открытые страны попадают в постоянную коллекцию.
- Деньги, инвентарь, открытые страны и количество тапов сохраняются в браузере через localStorage.
- Звуки генерируются на устройстве через Web Audio API; внешние аудиофайлы не требуются.
- Адаптивный интерфейс для телефонов и компьютеров.

## Опубликовать на GitHub Pages
1. В репозитории нажми **Add file → Upload files**.
2. Загрузи с заменой `index.html`, `style.css`, `game.js`, а также `logo.png`.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери `Deploy from a branch`, ветку `main`, папку `/(root)`, затем **Save**.
5. После публикации открой `https://USERNAME.github.io/REPOSITORY/`.

## Примечание
`logo.png` — графический логотип игры. Не удаляй его: главная страница использует этот файл. Для публикации в Яндекс Играх проверь актуальные требования платформы и подключение SDK отдельно.
