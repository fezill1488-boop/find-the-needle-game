# НомерЗнаток — обновление v3

Мобильная браузерная игра-кликер с номерными знаками.

## Обновление на GitHub Pages
1. Замените в корне репозитория `index.html`, `style.css`, `game.js` и `logo.png`.
2. Нажмите **Commit changes** и дождитесь публикации GitHub Pages.
3. Откройте сайт и обновите страницу. В `index.html` добавлена версия `?v=3` для принудительного обновления CSS/JS-кэша.

## Механики
- Стартовый баланс 10 000 монет; прокрутка стоит 200 монет.
- Выбор стран, случайные номерные знаки и редкости.
- Инвентарь на 30 мест; +1 место стоит 5 000 монет.
- Продажа номеров, коллекция, прогресс типов номеров по стране.
- Мини-игра «Угадай страну».
- Сохранение прогресса в localStorage.

Если кнопка покупки отключена, текущий баланс ниже 5 000 монет.


Обновление v5: во вкладке «Страны» доступны переключатели типов номеров для каждой страны. Такси открывается после 1 000 прокруток страны, полиция — после 5 000, военные — после 10 000. Правильный ответ в мини-игре «Угадай страну» начисляет 200 монет.
