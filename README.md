# НомерЗнаток — коллекционный кликер

Оригинальная мобильная браузерная игра на HTML/CSS/JavaScript без внешних библиотек.

## Возможности
- Начальный баланс 10 000 монет; одна прокрутка стоит 200 монет.
- Игрок выбирает страны, номера которых могут выпасть. Россия выбрана по умолчанию.
- Инвентарь на 30 мест и магазин: +1 место стоит 5 000 монет.
- Пять редкостей номерных знаков с разной стоимостью.
- Отдельный прогресс прокруток для каждой страны: гражданские доступны сразу, такси с 1 000, полицейские с 5 000, военные с 10 000 прокруток этой страны.
- Продажа номеров по одному или всех сразу.
- Мини-игра «Угадай страну».
- Коллекция стран, эффекты звука на Web Audio API, сохранение прогресса через localStorage.

## Запуск
Открой `index.html` в современном браузере либо опубликуй файлы в корне репозитория GitHub и включи GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Для публикации в Яндекс Играх понадобится отдельно интегрировать SDK Яндекс Игр, если нужны рекламные и платформенные функции. Внешние изображения/аудиофайлы не требуются, кроме `logo.png`.
